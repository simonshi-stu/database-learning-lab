启动向导：API / 进程 / 端口 / 数据库各做什么

API（FastAPI）

接收 HTTP 请求、校验、调用业务函数、返回 JSON。它不存数据，只转发与编排。

进程

运行中的程序实例。API 一个进程、后台 worker 另一个进程；各自独立崩溃互不拖累。

端口

本机上的门牌号：8022 课程、8021 原实验室、55433 PostgreSQL。客户端靠 host:port 找到服务。

数据库（PostgreSQL）

唯一持久真相：业务行+Outbox 事件同事务落库；API/worker 重启数据仍在。
